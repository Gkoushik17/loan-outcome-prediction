# Loan Outcome Prediction

## Project Overview
This project explores historical loan application and repayment data to identify patterns associated with good and bad loan outcomes.

## Objectives
- Understand the structure and quality of the datasets.
- Perform exploratory data analysis.
- Prepare data for machine learning.
- Compare classification models.
- Evaluate model performance using precision, recall, F1-score, and ROC-AUC.
- Identify limitations and recommend improvements.

## Models Evaluated
- Logistic Regression
- Extra Trees
- Gradient Boosting
- Random Forest
- Support Vector Machine (SVM)

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Structure
- `notebooks/` — Analysis and model development
- `outputs/` — Charts, reports, and model evaluation results
- `presentation/` — Assessment presentation
- `notes/` — Project notes

## Important Limitations
The dataset has incomplete customer matching and potential selection bias. Model performance is moderate, so the results should be treated as exploratory rather than used directly for lending decisions.

## Data Privacy
The original customer-level dataset is excluded from this public repository.
